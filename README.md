# WB 진로독서

초·중·고 학생을 위한 진로 맞춤 비문학 독서 앱웹 — WB 독해력학원 · 웩슬러브레인센터

- **학생 앱**: https://whdudwns33-wb.github.io/wb-reading/
- **강사 검수 뷰어**: https://whdudwns33-wb.github.io/wb-reading/review.html

## 기능
매일 1지문(진로·레벨 맞춤) · 의미 단위 끊어 읽기 · 어휘/한자 풀이 · 영어 대역 · 선택 문제 풀이 · 더 깊이 보기(논문·연계도서) · 읽기 근육 훈련(끊어 읽기 3단계, 어휘 간격 반복, 한자 카드, 붉은 책 요약) · 탐구보고서 위저드 · PWA(홈 화면 설치·오프라인)

## 운영
이 저장소는 **배포 전용 미러**입니다. 원본 소스와 콘텐츠 파이프라인(주간 소재 스캔·검수 흐름)은 `wb-site` 저장소의 `reading/` 폴더에서 관리하며, 변경 시 이 저장소로 동기화됩니다. 콘텐츠 검증: `node content.test.cjs`
