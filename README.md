# WB 진로독서

초·중·고 학생을 위한 진로 맞춤 비문학 독서 앱웹 — WB 독해력학원 · 웩슬러브레인센터

- **학생 앱**: https://whdudwns33-wb.github.io/wb-reading/
- **강사 검수 뷰어**: https://whdudwns33-wb.github.io/wb-reading/review.html

## 기능
매일 1지문(진로·레벨 맞춤) · 의미 단위 끊어 읽기 · 어휘/한자 풀이 · 영어 대역 · 선택 문제 풀이 · 더 깊이 보기(논문·연계도서) · 읽기 근육 훈련(끊어 읽기 3단계, 어휘 간격 반복, 한자 카드, 붉은 책 요약) · 탐구보고서 위저드 · PWA(홈 화면 설치·오프라인)

## 운영
이 저장소는 **배포 전용 미러**입니다. 원본 소스와 콘텐츠 파이프라인(주간 소재 스캔·검수 흐름)은 `wb-site` 저장소의 `reading/` 폴더에서 관리하며, 변경 시 이 저장소로 동기화됩니다.

### 점검·집필 도구

| 명령 | 하는 일 |
|---|---|
| `node content.test.cjs` | 콘텐츠 무결성 (끊어 읽기 이어붙이기·글자 수·어휘·출처 모양) |
| `node split.test.cjs` | 학년대 분할본이 원본과 같은지 |
| `node srccheck.mjs` | 출처 82개를 하나씩 실제로 받아 **본문에 근거가 있는지** 확인 (4분) |
| `node srccheck.mjs --selftest` | 위 판정 규칙만 확인 (망 불필요, 1초) |
| `node chunk.mjs --band L3 "문단"` | 의미 단위 끊어 읽기 **초안** 생성 |
| `node chunk.mjs --eval --holdout` | 초안 생성기가 사람 판단과 얼마나 맞는지 |
| `node linkcheck.mjs` | 딥링크 생존 확인 (상태 코드만) |

끊어 읽기 규칙은 [의미단위-끊어읽기-규격.md](의미단위-끊어읽기-규격.md)에 정리해 두었습니다 — 교재나 다른 앱에서 참고할 수 있습니다.
